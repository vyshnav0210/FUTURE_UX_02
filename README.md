**V Unisex Salon Booking App UI/UX**



A salon booking mobile application UI/UX design created using Figma.

This project focuses on providing a simple and user-friendly experience for customers to explore salon services, book appointments, and receive booking confirmations through a clean interface.



The application follows a dark theme with cyan and gold accent colors to create a modern salon brand identity.



**Project Overview**



The V Unisex Salon Booking App was designed as a mobile UI/UX practice project for salon appointment booking systems. The design includes multiple screens connected through Figma prototype mode to simulate a basic mobile app workflow.
