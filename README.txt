# 💇 V Unisex Salon App – UI/UX Design

> Mobile salon booking app UI designed in Figma

Designed by **Vyshnav**

---

# 📌 Project Overview

This project is a modern mobile salon booking app UI/UX design created using Figma.

The app allows users to:

- Browse salon services
- Search services
- Book appointments
- Choose time slots
- View booking confirmation

---

# 🎯 Features

- Splash Screen
- Login Screen
- Home Screen
- Search Screen
- Haircut Details
- Massage Details
- Facial Details
- Hair Colour Details
- Appointment Booking
- Booking Success Screen
